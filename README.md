# GitHub Hosts Updater

Windows 桌面应用，一键下载最新 GitHub 加速 hosts、对候选 IP 测速优选、更新本地 hosts 文件并刷新 DNS 缓存。

## 功能特性

- **一键更新**：点击按钮自动完成下载 → IP 优选 → 备份 → 合并 → 写入 → 刷新 DNS 全流程
- **自动提权**：非管理员运行时自动弹出 UAC 提权窗口
- **五源容错**：优先从 [GitHub520](https://github.com/521xueweihan/GitHub520)（专属 CDN，无需访问 GitHub）和 [fetch-github-hosts](https://github.com/Licoy/fetch-github-hosts) 下载，失败自动切换 ghfast.top 加速、GitHub Raw，最后回退到 Gitee 镜像
- **IP 优选测速（三层验证）**：归并所有数据源的候选 IP，依次做 ① 稳定性测速（每个 IP 连续 TCP 测 4 次、间隔 1 秒，全部成功才可用，淘汰间歇性抖动的 IP）→ ② TLS 握手验证（带 SNI 的真实 TLS 握手，可发现「TCP 通但 TLS 被丢弃」的 IP，失败自动换次优候选）→ ③ 写后验证（写入 hosts 后对 github.com 发真实 HTTPS 请求，失败自动更换候选 IP 重写）。可在界面上勾选开启/关闭，静默模式加 `--no-speedtest` 跳过
- **自动备份**：每次更新前自动备份原 hosts 文件到 `~/.gh_hosts_backup/`
- **智能合并**：只替换 GitHub hosts 标记段，不影响你已有的其他 hosts 配置
- **一键恢复**：支持从最近一次备份还原 hosts
- **静默模式**：支持 `--silent` 参数，可配合任务计划程序实现自动定时更新
- **实时日志**：GUI 内显示完整运行日志，便于排查问题
- **日志持久化**：所有运行日志自动保存到 `~/.gh_hosts_logs/` 目录，按日期归档

## 快速开始

### 方式一：直接运行 Python 脚本（需已安装 Python 3.8+）

```bash
# 安装依赖（仅需一次）
python -m pip install -r requirements.txt

# 运行（右键以管理员身份运行 cmd，或运行后自动提权）
python main.py
```

### 方式二：打包成独立 exe（推荐）

1. 双击运行 `build.bat`（会自动安装依赖并打包）
2. 打包完成后，可执行文件位于 `dist\GhHostsUpdater.exe`
3. 双击运行即可（已内置 UAC 自动提权）

> 打包后的 exe 是单文件，约 10-15MB，可直接拷贝到任意 Windows 机器运行，无需安装 Python。

## 设置自动更新（可选）

打包完成后，右键以管理员身份运行 `install_autoupdate.bat`，会在 Windows 任务计划程序中注册一个每 6 小时执行一次的静默更新任务（已注册的任务可用 `schtasks /change /tn "GitHub Hosts Auto Updater" /ri 60` 改为每小时，更及时应对间歇性阻断）。

- 查看任务：任务计划程序 → 任务计划程序库 → `GitHub Hosts Auto Updater`
- 手动删除任务：
  ```cmd
  schtasks /delete /tn "GitHub Hosts Auto Updater" /f
  ```

## 工作原理

1. 并发从 5 个数据源下载 hosts：GitHub520（raw.hellogithub.com）、fetch-github-hosts（hosts.gitcdn.top）、ghfast.top 加速、GitHub Raw、Gitee 镜像，任一成功即可用，多源数据共同参与优选
2. 解析所有源内容，归并出每个域名的候选 IP 列表（去重）
3. 稳定性测速：对全部候选 IP 的 443 端口并发 TCP 测速（每个连续测 4 次、间隔 1 秒，须全部成功，超时 3 秒淘汰），过滤间歇性抖动的 IP
4. TLS 握手验证：对每个域名的最优候选做带 SNI 的真实 TLS 握手，发现「TCP 通但 TLS 被丢弃」的 IP 时自动换次优候选（最多 3 轮）
5. 备份当前 `C:\Windows\System32\drivers\etc\hosts`，清理旧标记段（含旧版 `# Generated by Github Hosts start/end` 段），把新段写入 hosts 文件末尾
6. 执行 `ipconfig /flushdns` 刷新 DNS 缓存
7. 写后验证：对 github.com 发真实 HTTPS 请求验证，失败则自动更换候选 IP 重写并重验

## 注意事项

- 修改 hosts 文件需要管理员权限，程序会自动请求提权
- 杀毒软件可能会拦截 hosts 文件修改，如有提示请选择"允许"
- 本程序只管理 GitHub 相关域名的 hosts 条目，不会删除你已有的其他配置
- 备份文件位于 `C:\Users\<你的用户名>\.gh_hosts_backup\`
- 运行日志位于 `C:\Users\<你的用户名>\.gh_hosts_logs\`，可用于排查问题
